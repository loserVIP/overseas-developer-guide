## 一、 Google Play 开发者生态

### 1. 账号申请与实名验证
- **个人号 vs 企业组织账号选择**：了解两者的审核权重与存活周期。[详细对比解析](https://fatevia.cn/google-play-developer-account/)
- **DUNS（邓白氏码）踩坑要点**：企业名称与营业执照英文翻译必须 100% 对应。
- **支付拒付排查**：提示信用卡被拒或交易失败代码（OR-CCSEH 等）的根本成因。[支付报错排错步骤](https://fatevia.cn/blog/articles/google-developer-account-payment-failed-how-to-fix.html)

### 2. 封测与上架防关联
- **20人14天封闭测试避坑**：如何保证测试活跃度与通过率，避免“测试无效”。
- **环境隔离要求**：独立干净 IP、指纹浏览器与设备指纹的防关联隔离方案。
